# DLP 批量解密工具

针对透明加密（DLP）文件系统的**批量解密工具**。把加密的 Excel / Word / PPT / PDF 文件解密为明文副本，输出到明文区 `C:\解密文件`。

## 功能特性

- **四种格式全支持**：Excel（xls/xlsx/xlsm/xlsb/xlt/xltx）、Word（doc/docx/docm/dot/dotx/dotm）、PowerPoint（ppt/pptx/pptm/pps/ppsx/ppsm）、PDF
- **首次启动引导**：首次打开自动弹出初始配置说明（绿盾申请解密 → 另存为到 `C:\解密文件`），确认后不再弹出；说明可在右上角「⋯ → 首次使用说明」随时查看
- **批量解密**：一次处理多个文件/整个文件夹，按类型分组并行驱动解密程序
- **右键菜单一键解密**：在资源管理器中选中文件右键 → 「DLP 一键解密」，支持多选（单实例，只开一个窗口）
- **企业极简 UI**：近黑主色、状态徽章、进度条、逐文件实时日志、应用内通知
- **两段式进度 + 随时停止**：准备/解密分段显示进度，不会出现"进度条满格却像卡死"；处理中可点「停止」
- **单实例架构**：全系统只有一个主窗口，后续右键操作自动转发给已开窗口

## 工作原理

DLP 透明加密驱动只对**白名单进程**解密，且**只有"另存为"才会把明文落盘**（2026-09-29 真机实测）：

| 文件类型 | 解密程序 | 触发方式 |
|---|---|---|
| Excel/Word/PPT | 微软 Office | COM（Dispatch）打开 → **另存为**到明文区（`SaveAs`/`SaveAs2`，保持原格式） |
| PDF | WPS `wps.exe` | 命令行启动 → 依赖驱动落盘（`wpspdf.exe` 不在白名单） |

工具把源文件复制为明文区临时副本 → 用白名单程序打开副本 → 另存为到最终路径 → 校验文件头为明文（ZIP/OLE/PDF）→ 删除临时副本。

> **实测结论（重要）**：早期版本仅"打开文件并等待落盘"，实测驱动**不会**因打开而落盘（观察 23 秒仍为密文）；改为另存为后约 1.5~2.5 秒/文件即可产出明文。

## 使用说明

### 直接使用（无需安装）

1. 下载 `dist/DLP批量解密工具.exe`
2. **首次启动**：按引导弹窗完成初始配置——用绿盾正常流程申请解密一个文件并保存，导出方式选「另存为」、保存位置指定 `C:\解密文件`（绿盾自动创建，无需手动建），完成后点「我已完成配置」
3. 拖入文件/文件夹，或点「添加文件」，再点「开始解密」
4. 解密副本输出到 `C:\解密文件`
5. 可双击 `注册右键菜单.bat` 启用右键菜单

### 从源码运行

```bash
pip install pywin32 tkinterdnd2 pillow
python decrypt_gui.py
```

### 重新打包 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean "DLP批量解密工具.spec"
# 产物：dist/DLP批量解密工具.exe
```

## 项目结构

```
batch_decrypt/
├── decrypt_core.py        # 解密核心（COM 批量 + WPS PDF 启动器 + 重试机制）
├── decrypt_gui.py         # 图形界面（企业极简风格 + 单实例锁 + 队列转发）
├── context_menu.py        # 右键菜单注册/卸载（HKCU，免管理员）
├── DLP批量解密工具.spec   # PyInstaller 打包配置
├── 注册右键菜单.bat        # 一键注册右键菜单
├── 卸载右键菜单.bat        # 一键卸载右键菜单
└── dist/
    └── DLP批量解密工具.exe # 打包好的可执行文件
```

## 已知限制

- PDF 解密依赖本机安装 WPS（`wps.exe`），且该程序必须在 DLP 白名单内
- 右键菜单指向 exe 当前位置，移动 exe 后需重新注册（双击 `注册右键菜单.bat`）
- 输出目录固定为 `C:\解密文件`（可在 `decrypt_core.py` 的 `PLAINTEXT_DIR` 修改）
